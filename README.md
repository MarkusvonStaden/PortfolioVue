# PortfolioVue (Nuxt 3)

Portfolio site migrated to Nuxt 3 with static generation.

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

## Production Build

```bash
npm run build
```

## Static Generation

```bash
npm run generate
```

## Notes

- Static assets and PHP mail handler live in `public/`.
- Contact form posts to `/sendmessage.php`.
